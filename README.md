# MCP Bundle Setup

Kumpulan konfigurasi dan server MCP (Model Context Protocol) untuk Antigravity / Gemini CLI di Termux/Linux.

## 📦 Isi Server
- `memory`: MCP memory server (`@modelcontextprotocol/server-memory`)
- `sequential-thinking`: Sequential thinking MCP server (`@modelcontextprotocol/server-sequential-thinking`)
- `token-saver`: Custom lightweight tool server (`server.js`)

## 🚀 Cara Pasang Ulang (Restore)

```bash
git clone <URL_REPO_ANDA> ~/mcp-setup
cd ~/mcp-setup
bash install.sh
```
